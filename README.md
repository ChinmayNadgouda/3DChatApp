# 3DChatApp
A dynamic chat application using Node.js and React. 

## To start a backend server using Node
1. Create a directory called as server.
2. Enter the directory.
3. Run the following to initialise a NodeJs backend server
```bash
npm init -y
``` 
4. Install express 
```bash
npm install express
```
5. Create index.js (Entry point to our backend)
